How it works

  1. Create a will. Name an heir (any wallet — an Agent ID holder releases right after the deadline, anyone else one year later), pick a check-in interval (e.g. every 30 days) and a grace period, and write instructions for your heir.
  2. Check in. As long as you check in before the deadline, nothing happens. Each check-in resets the clock.
  3. If you go silent… once the deadline + grace period pass, your heir can release the will and read your instructions — immediately with an Agent ID, or one year later without one. Only the named heir can ever release it; no one can act for them.

AgentWill never holds or moves anyone's funds. There is no fee, no payable function, and no withdrawal. The contract only stores wills and their status.

Create a will

Only Agent ID holders can create a will. Registration is free except gas (about 0.0004 BNB on BSC).

Privacy warning: everything on a blockchain is public. Your will message can be read by anyone with an RPC call, even though this app only shows it to you and your heir. Never put secrets, private keys, seed phrases or passwords in a will message. Encrypted messages are planned for v2.

Details for the curious

  • Contract: AgentWill.sol — open source, verified on BscScan. The deployer can only pause in an emergency; there is no way to move funds because the contract holds none.
  • Agent ID check: creating a will requires an Agent ID (balanceOf(msg.sender) > 0 on the SPACE ID Agent ID contract, 0x60b9…22f on BNB Chain). Releasing is immediate with one; without one, the same heir can still release one year after the deadline (the slow path).
  • Release rule: a will becomes releasable strictly after last check-in + interval + grace period (fast path, heir holds an Agent ID), or one year after that (slow path, same heir, no Agent ID needed).
  • Built for the Agent ID Hackathon (Binance Wallet × BNB Chain), December 2026.
